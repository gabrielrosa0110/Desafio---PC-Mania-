Uso de IA

Durante o desenvolvimento deste projeto, utilizei Chatgpt como uma ferramenta de apoio para tirar dúvidas sobre Java, entender melhor o diagrama UML e organizar a estrutura das classes.

O código não foi simplesmente copiado e colado. Eu escrevi o projeto manualmente, acompanhando cada parte, fazendo ajustes e buscando entender o funcionamento do que estava sendo implementado.

Algumas dúvidas que consultei com a IA foram, por exemplo:

Como declarar em Java as classes mostradas no diagrama UML?
Como representar relacionamentos entre classes sem usar ArrayList?
Como armazenar vários computadores usando arrays?
Quando é realmente necessário criar getters e setters?
Como implementar o método calculaTotalCompra()?
Como usar a multiplicidade 0..1, * e 2..* do UML no código?
Como criar e organizar a classe Main para realizar as compras?
Como criar um método utilitário static para a classe ProcessarPedido?
Como organizar as classes em pacotes?

A IA foi utilizada como suporte durante o desenvolvimento e aprendizado, principalmente para explicações, correção de dúvidas e orientação na construção do código.
